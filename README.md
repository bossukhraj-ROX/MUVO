# MUVO
Muvo - Move Out Deposit Evidence Organiser 
MUVO

Move out. Stay organised.

MUVO is a move-out deposit toolkit for UK renters. It helps users document property condition, organise photos and inspection notes, track proposed deposit deductions, prepare factual email drafts, and export an evidence report.

Features

* Room-by-room property inspection checklist
* Photo evidence and condition notes
* Deposit deduction tracker
* Editable email templates
* Printable evidence report
* Local browser storage and project backups

Privacy

MUVO is designed to keep project data in the user’s browser. It is an independent tool and does not guarantee deposit returns or provide legal advice.

Status

Early-stage MVP in development.
